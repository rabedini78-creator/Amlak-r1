املاک آروان ابهر — بسته اولیه انتشار روی Netlify

محتویات:
- index.html: نسخه اصلی برنامه وبی که از فایل HTML دریافت‌شده استخراج شده است.
- images/: لوگو و آیکون‌های ارسالی.
- netlify.toml، robots.txt، sitemap.xml و site.webmanifest.

نکته مهم درباره عملکرد:
این نسخه HTML از رابط اختصاصی Claude برای پایگاه داده، فایل‌های تصویری آپلودشده و تشخیص مالک استفاده می‌کند.
در خارج از Claude، این اتصال‌ها خودکار در دسترس نیستند. بنابراین این بسته، نسخه انتقال اولیه ظاهر و کد برنامه است و هنوز نسخه نهایی با پنل مدیریت امن و پایگاه داده مشترک برای همه کاربران نیست.
آگهی‌ها و تصاویر قبلی که با شناسه‌های داخلی Claude ذخیره شده‌اند ممکن است در میزبانی مستقل بارگذاری نشوند.
برای فعال‌سازی مدیریت واقعی و ذخیره دائمی چندکاربره باید یک سرویس مستقل مانند Supabase/Firebase پیکربندی شود؛ کلیدهای محرمانه نباید داخل HTML قرار بگیرند.

روش انتشار اولیه:
تمام محتویات این پوشه را در Netlify از مسیر Add new project > Deploy manually بارگذاری کنید.
